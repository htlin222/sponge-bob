# 台詞截圖（`bob still`）

把金句庫裡的一句台詞，從 Drive 上的原片抓畫面，下方加黑底字幕與出處：

```
「拜託海綿寶寶，你沒問題的，
　就像開玉米罐一樣。」
                 —— 珊迪｜《海綿寶寶》S08 ep161〈月球遊記〉6:36
```

## 一次出 6 張讓使用者挑

同一句台詞的不同瞬間，表情和動作差很多（閉眼、攤手、張嘴），單抓一格常常剛好是怪表情。
所以預設**以台詞中點為中心、每 0.5 秒抓一張、共 6 張，全部落在台詞前後 3 秒內**
（排不下會自動縮小間距），另外附一張編號總覽圖。

**一定要把總覽圖給使用者看，讓他挑編號**，不要自己替他決定只給一張。
可以附上你的推薦（例如「4 號珊迪攤手最像在鼓勵」），但最後由使用者選。

## 步驟

1. **找出台詞在哪一集、什麼時間**：用 `uv run bob ask "處境"`，或直接查 Turso 的 `cues`／`quotes`。
2. **判斷說話者**：字幕沒有標說話者，`quotes.speaker` 是模型猜的、常常是「A／B」。
   看前後文決定是誰，填進 `--speaker`；拿不準就不填（出處只寫集數）。
3. **產生候選**：

   ```bash
   uv run bob still ep161 --text "就像開玉米罐" --speaker 珊迪
   ```

   - `episode`：集名片段（`ep161`、`月球遊記`），必須只對到一集。
   - `--text`：台詞片段，忽略標點與換行，可跨好幾句字幕；或改用 `--at 6:36`。
   - 單元名會依時間點從「月球遊記／蟹老闆渡假去」自動取前段或後段；不對就用 `--title`。
   - 字幕有聽寫錯字時用 `--caption "第一行 / 第二行"` 改寫，**不要把錯字印在圖上**。
   - 要更多選擇：`--count 9 --step 0.33`；台詞前後的反應鏡頭：`--window 5`。

4. **給使用者挑**：用 SendUserFile 傳 `*_contact.png`（總覽），使用者挑好編號後再傳那一張 `*_N.png`。

## 注意

- 輸出在 `scratch/stills/`（已 gitignore）。截圖與字幕是有版權的內容，**不要 commit 進這個公開 repo**。
- 影片是透過 Drive API 串流抓單格，不下載整部；需要 `~/.config/sponge-bob/` 的 Drive token 和 `ffmpeg`。
- 原片多為 640×480，輸出放大到寬 1280，近看會有點糊，手機分享沒問題。
