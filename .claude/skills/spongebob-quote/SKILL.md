# 找海綿寶寶台詞

金句庫在 Turso（`bob` 預設連線）：320 集、約 6,500 段金句，每段都有「使用情境」描述和語意向量。

## 一輪找完：語意搜尋 → 你自己挑

在對話裡**你就是挑選的模型**，不要用 `--pick`（那會再叫一次 `claude -p`，多 6 秒）。

```bash
uv run bob ask "朋友怕得不敢嘗試" -n 15
```

- 約 1–2 秒，列出語意最接近的段落：台詞、說話者、集數、時間、★好引用程度、使用情境。
- **向量比對的是金句的「使用情境」欄**，那是「朋友……時」「被……時，用來……」的句型。
  **把使用者的話改寫成這種口吻再搜**，命中率差很多（實測）：

  | 使用者原話 | 改寫成情境口吻 | 目標台詞名次 |
  |---|---|---|
  | 朋友說暫時還不敢 | 朋友怕得不敢嘗試 | 13 → **1** |
  | 病人治不好了，想讓他舒服一點 | 朋友生病，想讓他舒服一點 | 6 → **2** |
  | 要上台報告好緊張 | 朋友很怕上台報告 | 311 → **3** |

  抽象詞（「緩和安寧」「陪伴」）幾乎搜不到，要換成劇中會發生的具體情境（「朋友傷心難過，想陪他」）。
- 處境有好幾個面向時（例如陪伴、告別、感恩），每個面向各寫一句情境、各搜一次，**同一則訊息平行送出**。
- 前幾名不一定最好：從結果裡依使用者的處境挑 3–6 段，依面向分組呈現。

## 具體名詞找不到時：關鍵字搜字幕

金句庫只收約 6,500 段，很多好台詞沒被標成金句；時事、名詞類的主題（選舉、大巨蛋、免費午餐、
學歷、市民）語意搜尋常常撈不到。這時直接搜全部 9.8 萬句字幕：

```bash
uv run bob grep 大巨蛋 偷工減料     # 含任一詞的字幕，依集數與時間排序
uv run bob grep 市長 投票 選舉
```

- 一個主題想幾個同義詞、劇中可能的說法一起搜（老鼠 → 害蟲、除蟲、衛生檢察官；學歷 → 大學、畢業、學位）。
  海底沒有的東西（老鼠、樹木少見）要換成劇中的對應物。
- 有命中就用 `bob ctx` 看前後文，常常會挖到整集同主題的劇情（〈下水道歷險記〉整集就是大巨蛋偷工減料）。

## 查前後文：這段在演什麼

```bash
uv run bob ctx ep068 7:41 --span 60
```

列出該時間點前後的字幕，`▶` 是正在播的那句。**推薦任何一句前都要看**，用來：

- 確認台詞在劇中的真正語氣（例如《章魚絕症》「起碼我可以讓你很舒服」其實是章魚哥裝病被照顧到受不了的反諷場面）。
- 確認劇情有沒有反轉：「金錢買不到真愛」的新娘其實是衝著祖傳秘方來的；「曾經深愛過」下一秒皮老闆就爬回去求凱倫。
  反轉可以當笑點，但要告訴使用者。
- 判斷說話者：字幕沒有標說話者，`speaker` 欄是模型猜的、常錯（〈我不是派美眉〉的告白標成章魚哥，其實是蟹老闆），
  出圖時再從畫面確認。

## 回答時要提醒

- 標出集數與時間（`S08E161《月球遊記》6:36`），方便使用者自己去看。
- 劇情脈絡和引用情境不合時要說（反諷、玩笑、裝病），尤其是嚴肅場合（安寧、喪親）。
- 字幕是 Whisper 聽寫，可能有錯字；有可疑字時建議引用前對影片確認。
- 使用者要做成圖時，接著用 `spongebob-still` skill。

## 注意

- 台詞內容有版權：只存在 Turso 和 `scratch/`，不要寫進 repo。
- 新增或重標金句後（`bob index`）會自動補向量；手動補：`uv run bob embed`。
